# 晚风对话

面向 vivo WATCH GT 2（BlueOS / orbitV）的轻量恋爱对话小游戏。游戏没有文字输入框，玩家只通过大按钮选择行为。

## 玩法

- 启动后先阅读背景，然后选择“直接恋爱”或“追求他人”。
- 每天自动随机一个场景，共 10 个场景。
- 每天 10 轮，每轮提供 3 个行为选项。
- 聊天区保留最近 10 轮消息，并在每次选择后自动滚到最新一条。
- 自动保存角色、天数、场景、轮次、聊天记录和好感度，下次启动可继续游戏。
- 白天有 10% 的概率切换场景；成功切换后依次降为 8%、6%、4%、2%、0%。
- 夜晚根据事件进入电话陪伴、家里或酒店，10 轮后女方睡着，强制结束当天。

## 固定文本

游戏共有 70,000 条固定句子，运行时不生成新句子：

| 内容 | 句子数 |
|---|---:|
| 10 个白天场景 | 50,000 |
| 场景过渡语 | 100 |
| 夜间事件结果 | 50 |
| 酒店隐藏场景 | 2,000 |
| 三种态度池 | 16,800 |
| 高风险动作专属反应 | 1,050 |
| 合计 | 70,000 |

每个白天场景 5,000 句，由 30 个行为池（各 150 句）、500 条环境句和 10 条场景过渡语组成。

## 轻量化设计

- 不使用角色图、背景图或场景图，只保留应用图标。
- 10 个场景和酒店正文会压缩成 LZ 字符串，写入 `src/data/scene_compressed.js`。
- 每天开始只解压当前场景的氛围句和过渡语；选择行为时才解压对应的 150 句行为池。
- 每个 560 句态度池再拆成 4 个 140 句小块，每轮只解压其中一块。
- 高风险动作反应仍按 35 句的小池加载。
- 页面 JS 约 1.3MB，release 安装包约 1.7MB。

`content/` 和 `src/assets/story/` 是生成出来的校对文本，已加入 `.gitignore`。运行生成脚本可以重新创建。

## 本地运行

安装依赖：

```bash
pnpm install
```

重新生成固定文本和压缩场景：

```bash
pnpm generate
```

浏览器预览：

```bash
pnpm preview
```

然后访问 `http://127.0.0.1:8766/`。

## BlueOS Studio

1. 用 BlueOS Studio 导入本目录。
2. 安装依赖后启动“预览窗口”。
3. 在手表模拟器中检查界面和对话。
4. 使用 release / production 打包，将 `dist` 中的 `.rpk` 上传到 orbitV 或安装到手表。

## 数据校验

生成脚本会检查：

- 10 个场景各 5,000 句
- 酒店 2,000 句
- 夜间 50 句
- 过渡语 100 句
- 总计 52,150 句
- 全部句子不重复
